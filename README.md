# SciGenius Chat

SciGenius Chat is an AI-powered assistant built with Next.js and Genkit. It is designed to answer questions about physics, friction, and general knowledge, with support for both Indonesian and English languages.

## Features

- **AI Chat Interface**: Interactive chat UI built with modern React components.
- **Multilingual Support**: Ask questions in English or Indonesian.
- **Physics Focus**: Specifically tailored for questions related to physics and friction.
- **Session Management**: Keep track of conversation histories.
- **Powered by Genkit & Gemini**: Utilizes the Google Genkit framework.

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:9002](http://localhost:9002) with your browser to see the application.

## Genkit Development

To run the Genkit developer UI:

```bash
npm run genkit:dev
```
