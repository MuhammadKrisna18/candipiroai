# **App Name**: SciGenius Chat

## Core Features:

- Bilingual Question Submission: Users can submit questions in either Indonesian or English. The AI will automatically detect the language for processing.
- AI Physics Explanation Tool: An AI tool providing detailed and context-aware explanations specifically for physics concepts, with a focus on friction, adapted to the detected input language.
- AI General Knowledge Answers: An AI tool capable of answering a broad range of general knowledge questions accurately, delivering responses in the user's preferred or detected language.
- Interactive Chat History Display: A clear and easily navigable display of past conversations, allowing users to review previous questions and answers.
- User Session Management: Allow users to log in/out to save their chat history, enabling continuity across sessions.

## Style Guidelines:

- Primary interactive color: A balanced and professional blue (#0F6CBD) symbolizing clarity and intelligence, designed to stand out against the light background.
- Background color: A very light, subtle blue-gray (#EBF2F7) providing a clean and modern canvas that promotes readability and a calm user experience.
- Accent color: A soft, refreshing cyan (#6ECACB) to highlight important information and call-to-action elements, offering a pleasant contrast while maintaining a harmonious analogous palette.
- Primary font: 'Inter' (sans-serif), chosen for its modern, neutral, and highly readable characteristics, making it ideal for both chat interactions and detailed explanations in a bilingual context.
- Utilize minimalist line-art icons that communicate core functionalities clearly, such as language switching, question submission, and subject matter (e.g., a magnifying glass for general knowledge, a gear or force arrows for physics).
- A responsive, single-column chat interface optimized for easy content consumption, featuring a fixed input area and a scrollable history. Clear segmentation will differentiate AI-generated responses from user input.
- Implement subtle, smooth transitions for chat message entry and content loading states, providing a polished and fluid user experience without distracting from the information.
